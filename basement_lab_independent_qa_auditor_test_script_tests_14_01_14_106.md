* **`[FULL-AUDIT]`** — Run whenever adding/editing exercises, modifying 2-stage photo assets/slugs, updating analytics math, or preparing a milestone checkpoint.

# Agent Execution Protocol

1. **Environment Initialization:** Clear browser state or initialize an isolated session context. Verify that `localStorage` keys (`basement_logs`, `basement_cardio_logs`, `basement_sauna_logs`, `basement_coach_context`, `basement_active_goal`, `basement_temp_injuries`, `basement_limits`, `basement_custom_catalog`, `basement_trainer_directives`, `basement_trainer_notes`, `basement_gemini_api_key`) initialize with empty/unseeded defaults for new/fresh accounts and can be seeded or reset deterministically (taking active Supabase session/auto-sync in `basement-db.js` into account).
2. **State Seeding:** Prior to running each test block, inject the exact pre-requisite JSON payloads into `localStorage` as specified in the test actions.
3. **Execution & DOM Inspection:** Target the specified target module HTML file or master wrapper. Programmatically execute user actions, trigger events, and inspect the rendered DOM, element visibility, styling tokens, and browser console output.
4. **Evidence Collection:** Record DOM element IDs, text content, CSS computed styles, image load states (`img.complete && img.naturalWidth > 0`), console log/error arrays, and `localStorage` diffs.
5. **Scoring & Reporting:** Mark the test item as **PASS** if and only if 100% of the listed Pass Criteria are satisfied. If any criteria fail, mark **FAIL** and append structural evidence including line numbers, DOM state snippets, and exact reproduction steps.
