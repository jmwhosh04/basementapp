To ensure repeatable, context-independent test execution by autonomous QA Auditor agents, follow this step-by-step evaluation procedure:

5. **Scoring & Reporting:** Mark the test item as **PASS** if and only if 100% of the listed Pass Criteria are satisfied. If any criteria fail, mark **FAIL** and append structural evidence including line numbers, DOM state snippets, and exact reproduction steps.
